## Overview

Figma was founded in 2012 by Dylan Field and Evan Wallace, who met as computer science students at Brown University. Field left Brown to pursue the project full-time after receiving a Thiel Fellowship grant of $234,460. Unlike earlier design tools built as native desktop applications, Figma was built to run in a web browser using WebGL, which allowed multiple people to view and edit the same file simultaneously. After an invite-only preview starting in December 2015, Figma launched publicly on September 27, 2016.

In September 2022, Adobe announced an agreement to acquire Figma for approximately $20 billion, which would have been Adobe's largest acquisition to date. The deal drew scrutiny from antitrust regulators, including the UK Competition and Markets Authority and the European Commission, over concerns it would reduce competition in the design software market. Facing an unclear path to regulatory approval, Adobe and Figma mutually terminated the agreement on December 18, 2023, with Adobe paying Figma a $1 billion termination fee. Figma has continued to operate as an independent company and went public via IPO in 2025.

## Key Features

- **Real-time multiplayer editing** — Multiple users can view and edit the same file simultaneously, with cursors and changes visible live
- **Vector-based design tools** — Frames, components, auto layout, and constraints for building interface designs
- **Prototyping** — Interactive, clickable prototypes built directly from design frames
- **Dev Mode** — A dedicated mode for developers to inspect layers, view generated code snippets, and export assets
- **FigJam** — A companion online whiteboard for brainstorming, diagramming, and workshops, launched in 2021
- **Plugin and API ecosystem** — Third-party plugins and REST API for extending functionality and integrating with other tools

## Use Cases

- **UI/UX designers** — Designing and prototyping websites, mobile apps, and software interfaces
- **Product teams** — Collaborative design reviews and handoff between designers and developers
- **Cross-functional teams** — Brainstorming and workshop facilitation using FigJam
- **Design system maintainers** — Building and sharing reusable component libraries across an organization

## Who It's For

Figma is aimed at UI/UX designers, product teams, and developers who need to collaborate on interface design in real time. It runs primarily in the web browser, with desktop applications available for Windows and macOS, and is offered through a freemium model with free, Professional, Organization, and Enterprise subscription tiers.
