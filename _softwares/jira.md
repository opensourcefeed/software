## Overview

Jira was released by Atlassian in 2002, originally built as a bug- and issue-tracking tool for software teams, taking its name from "Gojira," the Japanese name for Godzilla, as an internal nod to a competing bug tracker Atlassian's founders had used. It has since grown into Atlassian's flagship product, expanding from pure issue tracking into full agile project management with built-in support for Scrum boards, Kanban boards, sprints, and backlog management, and now anchors a broader Atlassian suite that includes Confluence for documentation and, since its 2017 acquisition, Trello for lightweight kanban boards.

Atlassian offers Jira in a cloud-hosted version (Jira Cloud) and previously offered a self-hosted Jira Server product, which was discontinued for new licenses in 2021 and fully retired from support in 2024; a self-managed option, Jira Data Center, remains available for organizations that need on-premises deployment, but it requires a substantially larger licensing commitment than Jira Cloud. Jira's data model — issues, projects, workflows, and custom fields — is highly configurable, which supports complex enterprise processes but also means administering a large Jira instance is itself a specialized skill at bigger organizations.

## Key Features

- **Scrum and Kanban boards** — Native support for sprint planning, backlogs, and kanban-style workflows
- **Customizable workflows** — Configurable issue types, statuses, and transitions per project
- **Advanced reporting** — Burndown charts, velocity reports, and cumulative flow diagrams for agile teams
- **Roadmaps** — Timeline views for planning epics and releases across teams
- **Atlassian ecosystem integration** — Native links to Confluence documentation and Bitbucket/GitHub code repositories
- **Marketplace apps** — Thousands of third-party plugins extending Jira's functionality

## Use Cases

- **Software development teams** — Sprint planning, bug tracking, and release management
- **Agile/Scrum workflows** — Backlog grooming, sprint boards, and velocity tracking
- **Enterprise IT service management** — Jira Service Management builds on the same platform for ticketing
- **Cross-team engineering coordination** — Linking issues across multiple teams and projects

## Who It's For

Jira is aimed at software development teams and larger organizations that need structured issue tracking with configurable workflows, tightly integrated with the rest of the Atlassian ecosystem. It's distributed on a per-user subscription basis for Jira Cloud, with Jira Data Center available as a substantially more expensive self-managed option for organizations with on-premises requirements.
