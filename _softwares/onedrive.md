## Overview

OneDrive traces back to SkyDrive, a Microsoft cloud storage service launched in 2007, which was rebranded to OneDrive in 2014 following a trademark dispute over the SkyDrive name. It is deeply integrated into Windows itself, with a built-in sync client shipped as part of the operating system since Windows 8.1, and into Microsoft 365, where it serves as the underlying storage layer for Word, Excel, and PowerPoint documents saved to the cloud, as well as file attachments and shared links used across Outlook and Microsoft Teams.

Because OneDrive is bundled into Windows, most Windows users encounter it by default even without actively choosing a cloud storage provider, and Microsoft has periodically prompted users to back up desktop folders (Desktop, Documents, Pictures) to OneDrive automatically as part of Windows setup. Storage quotas are shared across a Microsoft 365 subscription alongside Outlook.com email, and OneDrive for Business, used within organizational Microsoft 365 tenants, adds administrative controls, retention policies, and integration with SharePoint document libraries. All data is proprietary and hosted exclusively on Microsoft's infrastructure, with no self-hosted option.

## Key Features

- **Windows integration** — Built-in sync client shipped as part of Windows, with automatic desktop folder backup
- **Microsoft 365 integration** — Underlying storage for Word, Excel, PowerPoint, and Teams file sharing
- **File sync and share** — Cross-device sync with shareable links and configurable permissions
- **Version history** — Automatic file versioning with recovery of prior versions
- **Personal Vault** — An additional-authentication-protected folder for sensitive files
- **Known Folder Move** — Automatically redirects Desktop, Documents, and Pictures folders into OneDrive sync

## Use Cases

- **Windows users** — Automatic backup of default user folders on Windows PCs
- **Microsoft 365 subscribers** — Cloud storage for Office documents with real-time co-authoring
- **Businesses** — OneDrive for Business as part of a Microsoft 365 tenant, integrated with SharePoint
- **Cross-device access** — Files available from any device with a browser and Microsoft account

## Who It's For

OneDrive is aimed at Windows users and organizations already invested in Microsoft 365 who want cloud storage bundled with Office document collaboration. It's distributed on a freemium model with a limited free quota, and paid Microsoft 365 or OneDrive for Business plans for additional storage and administrative features; all data is hosted exclusively on Microsoft's servers with no self-hosting option.
