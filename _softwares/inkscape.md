## Overview

Inkscape began in 2003 as a fork of Sodipodi, an earlier open source vector drawing program, started by a group of developers who wanted faster, more community-driven releases and a codebase committed to the then-emerging SVG (Scalable Vector Graphics) W3C standard as its native file format. Rather than a proprietary format like Illustrator's `.ai`, Inkscape saves files as plain SVG, an open, XML-based format that's readable by web browsers and countless other design and development tools without any conversion step.

The project is released under the GPL-3.0-or-later license and developed by a volunteer community coordinated through the Inkscape open source project, with funding channeled through the non-profit Software Freedom Conservancy. Inkscape's tools cover path-based drawing, node editing, boolean shape operations, and text layout comparable to Illustrator's core feature set, though it has historically lagged behind Illustrator in areas like advanced typography, color management for print production, and some newer AI-assisted tools that remain exclusive to Adobe's Creative Cloud apps.

## Key Features

- **Native SVG format** — Files are saved as standard SVG, readable by browsers and other tools without conversion
- **Path and node editing** — Bezier and spiro curve tools with precise node-level control
- **Boolean path operations** — Union, difference, intersection, and other shape-combination tools
- **Text and typography** — Text-on-path, flowed text, and OpenType feature support
- **Extensions** — Python-based extension system for batch processing, import/export, and custom tools
- **Cross-platform** — Native builds for Linux, Windows, and macOS

## Use Cases

- **Logo and icon design** — Scalable vector logos and icon sets exported directly as SVG
- **Web and UI graphics** — Vector assets destined for web use, where native SVG output skips export/conversion steps
- **Technical and scientific illustration** — Diagrams and figures using precise path tools
- **Print design on a budget** — Posters, packaging mockups, and illustration without a subscription

## Who It's For

Inkscape is suited to designers, hobbyists, and open source contributors who want a capable vector editor without a subscription, particularly those working in SVG-native workflows like web graphics or open source projects. Professional print studios doing heavy CMYK color-managed production work may still find Adobe's ecosystem more complete, but for logo design, illustration, and general vector work, Inkscape covers the core toolset at no cost.
