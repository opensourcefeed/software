## Overview

Microsoft Edge originally launched in 2015 as Windows 10's default browser, built on Microsoft's own EdgeHTML rendering engine as a replacement for the aging Internet Explorer. That original engine struggled with web compatibility and adoption, and in 2020 Microsoft rebuilt Edge from scratch on top of Chromium, the same open source engine underlying Google Chrome, gaining near-total site and extension compatibility with Chrome in the process while keeping Microsoft's own branding and feature layer on top.

Because it's Chromium-based, Edge is closed source in the same way Chrome is: the open source Chromium project underneath is public, but Microsoft's proprietary additions — account sync tied to a Microsoft account, the Bing-integrated sidebar, Collections, and Copilot AI features — are closed. Edge is bundled with every Windows installation and set as the default browser, cannot be fully uninstalled on Windows without workarounds, and Microsoft has periodically prompted users attempting to switch default browsers to reconsider Edge, drawing antitrust scrutiny in some jurisdictions comparable to criticism aimed at Chrome's Google integration.

## Key Features

- **Blink rendering engine** — Chromium/Blink engine, giving near-total compatibility with Chrome extensions and sites
- **Copilot integration** — Built-in Microsoft Copilot AI assistant accessible from the sidebar
- **Vertical tabs and workspaces** — Tab organization features for managing many open tabs
- **Collections** — Save and organize web content, images, and links into shareable collections
- **Microsoft account sync** — Bookmarks, passwords, and history synced across devices tied to a Microsoft account
- **Built-in tracking prevention** — Configurable tracking protection levels (Basic, Balanced, Strict)

## Use Cases

- **Windows users** — Pre-installed default browser requiring no separate download
- **Microsoft 365 users** — Tighter integration with Office web apps and Microsoft accounts
- **Enterprise deployments** — Group Policy management options for organizations standardized on Windows
- **Chrome extension compatibility** — Access to the Chrome Web Store's extension catalog via Edge's add-ons store

## Who It's For

Microsoft Edge is aimed at Windows users who want a Chromium-based browser with deeper Microsoft account and Copilot integration than Chrome offers. It's distributed free of charge and pre-installed on Windows, with versions also available for macOS, Linux, Android, and iOS.
