## Overview

Adobe Illustrator was first released in 1987 for the Apple Macintosh, originally built around Adobe's own PostScript technology to bring precise, resolution-independent vector drawing to designers who had previously relied on manual paste-up and technical pen work. It grew alongside Adobe Photoshop into the standard pairing for professional graphic design — Photoshop for raster/photo editing, Illustrator for vector artwork — and remains the dominant tool for logo design, iconography, print production, and technical illustration across agencies and in-house design teams.

Illustrator moved from perpetual-license sales to the subscription-only Creative Cloud model in 2013, a change that drew significant criticism at the time but has remained the distribution model since. Files are saved in Adobe's proprietary `.ai` format, built on an internal PDF-compatible structure, and the application integrates tightly with other Creative Cloud apps such as Photoshop, InDesign, and Adobe Fonts. Illustrator is closed source and available only through a Creative Cloud subscription, with no free tier beyond a limited trial period.

## Key Features

- **Vector drawing tools** — Pen, curvature, and shape tools for precise, scalable path-based artwork
- **Typography** — Advanced type tools including variable fonts, glyph panels, and text-on-path
- **Artboards** — Multiple artboards per document for organizing related assets like icon sets or multi-page layouts
- **Gradient and pattern tools** — Freeform gradients, mesh gradients, and repeating pattern generation
- **Creative Cloud integration** — Shared assets, fonts, and libraries synced across Photoshop, InDesign, and other Adobe apps
- **Generative AI tools** — Adobe Firefly-powered generative recolor, vectorization, and pattern generation (subscription-gated)

## Use Cases

- **Logo and brand identity design** — Creating scalable logos, wordmarks, and brand style guides
- **Icon and UI asset design** — Vector icon sets and interface assets for digital products
- **Print production** — Packaging, posters, and technical illustration requiring precise vector output
- **Editorial illustration** — Vector-based illustration for publishing and advertising

## Who It's For

Adobe Illustrator is aimed at professional graphic designers, illustrators, and brand agencies who need industry-standard vector tools and deep Creative Cloud integration. It requires an ongoing Creative Cloud subscription and runs only on Windows and macOS, with no Linux support.
