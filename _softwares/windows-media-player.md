## Overview

Windows Media Player (WMP) is the default multimedia player included with Microsoft Windows since Windows 3.0 with Multimedia Extensions. It provides basic playback for common audio and video formats, a media library for organizing files, CD ripping to WMA and MP3, and playlist management.

WMP was once the dominant desktop media player, but its market relevance has declined significantly. Microsoft replaced it with Groove Music and Movies & TV in Windows 10, then reintroduced a modernized version in Windows 11. The legacy WMP remains available for compatibility.

## Key Features

- **Media library** — Organize audio and video files by metadata (artist, album, genre) with search and filtering
- **CD ripping** — Rip audio CDs to WMA, MP3, or WAV formats with automatic metadata lookup
- **Playlist management** — Create, save, and sync playlists across devices
- **DLNA streaming** — Stream media to DLNA-compatible devices on a local network
- **Visualizations** — Real-time audio visualizations during playback
- **Sync to portable devices** — Transfer music to compatible MP3 players and phones

## Use Cases

- **Windows home users** — Basic playback of music and video files stored locally
- **CD collectors** — Ripping CDs to digital files with metadata auto-tagging
- **Media library organizers** — Managing large collections of local music and video files

## Who It's For

Windows Media Player is for Windows users who want a built-in, no-additional-installation media player for everyday playback. It is proprietary, Windows-only, and tied to the Microsoft ecosystem. For users needing broader format support, cross-platform compatibility, or open source licensing, alternatives like VLC or mpv are available.
