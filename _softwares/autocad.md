## Overview

AutoCAD was first released by Autodesk in December 1982, making it one of the first significant CAD programs to run on personal computers rather than mainframes or dedicated CAD workstations. Its early availability on PC hardware helped establish Autodesk as a dominant player in the CAD market, and the DWG file format it introduced has since become a de facto standard for exchanging CAD drawings, used and supported by many competing and complementary tools.

Over four decades of development, AutoCAD has expanded from pure 2D drafting into 3D modeling, and Autodesk now offers industry-specific toolset variants (AutoCAD Architecture, AutoCAD Mechanical, AutoCAD Electrical, and others) built on the same core application. Since 2018, AutoCAD has been sold exclusively via subscription, having previously been available as a perpetual license.

## Key Features

- **2D drafting** — Precision vector-based drawing tools for technical drawings and construction documents
- **3D modeling** — Solid, surface, and mesh modeling for basic 3D design work
- **DWG file format** — Native format that has become the de facto standard for CAD file exchange
- **Industry toolsets** — Specialized command sets and libraries for architecture, mechanical, and electrical design
- **Parametric constraints** — Geometric and dimensional constraints to maintain design relationships
- **Cloud collaboration** — Autodesk Docs integration for sharing and reviewing drawings online

## Use Cases

- **Architecture and construction** — Floor plans, construction documents, and site drawings
- **Mechanical engineering** — Technical drawings and part diagrams for manufacturing
- **Electrical design** — Schematic and wiring diagrams using the AutoCAD Electrical toolset
- **Civil engineering and surveying** — Site plans and infrastructure drawings

## Who It's For

AutoCAD is aimed at architects, engineers, and drafters working in industries where DWG compatibility with clients, contractors, and regulatory bodies is a practical requirement. Its subscription pricing and industry-standard file format make it a common baseline tool in professional CAD workflows, particularly where interoperability with other Autodesk products matters.
