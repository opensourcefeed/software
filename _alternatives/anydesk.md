AnyDesk's free tier is limited to personal, non-commercial use, and its DeskRT codec and client code are closed source. RustDesk is the closest open source match, offering the same session-initiator model with cross-platform clients, and the option to self-host your own relay server instead of routing traffic through a vendor. Remmina is a better fit if you mainly need to connect to machines that already run a standard RDP, VNC, or SSH server, since it's a multi-protocol client rather than a full replacement for AnyDesk's own client-server system.
