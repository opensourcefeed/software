Switching from Chrome to an open source browser cuts off the telemetry and account-linked tracking that fund Google's advertising business, without necessarily giving up compatibility — Chromium-based options like Brave render sites identically to Chrome and support the same extensions. Firefox-based options like LibreWolf trade some Chrome extension compatibility for an independent rendering engine and stronger default privacy hardening. Both block ads and trackers out of the box, something Chrome requires extensions (increasingly limited by Manifest V2's deprecation) to approximate.
