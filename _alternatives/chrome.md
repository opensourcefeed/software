Switching from Chrome to an open source browser cuts off the telemetry and account-linked tracking that fund Google's advertising business, without necessarily giving up compatibility — Chromium-based options like Brave render sites identically to Chrome and support the same extensions. Firefox and Firefox-based options like LibreWolf run on Gecko, an independent rendering engine outside the Chromium/WebKit lineage, trading a small amount of extension compatibility for engine diversity and stronger default privacy hardening. All three block ads and trackers out of the box, something Chrome can now only approximate via Manifest V3 extensions, since Chrome has fully phased out Manifest V2 support. Tor Browser, also a Firefox ESR fork, goes further still by routing traffic through the Tor network for anonymity and censorship circumvention — a different use case from the faster, still-identifiable browsing Brave, Firefox, and LibreWolf offer, and one that comes at a real cost in speed and site compatibility.
