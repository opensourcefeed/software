TeamViewer's free tier is limited to personal, non-commercial use, and commercial licensing scales with the number of users, devices, and concurrent sessions. RustDesk offers a directly comparable client-server remote-access model under an open source license, with the option to self-host your own relay server instead of paying for named-user licensing. Remmina is a better fit if you mainly need to connect to machines that already run a standard RDP, VNC, or SSH server, since it's a multi-protocol client rather than a full replacement for TeamViewer's own client-server system.
